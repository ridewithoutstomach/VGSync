KVRouite - Notice for Qt, PySide6 and shiboken6
================================================================================

This folder documents the Qt components that KVRouite distributes as part of
its Windows build. It travels with the binaries in "_internal/qt".

On LINUX no Qt binary is distributed with KVRouite at all; PySide6 is installed
from PyPI or from the distribution's own packages by the user.

Files here:
  NOTICE.txt                this notice
  COMPONENTS.txt            the packages shipped, their versions and licenses
  CORRESPONDING-SOURCE.txt  where the source code is and how to get it
  COPYING.LGPL-3            GNU Lesser General Public License, version 3
  COPYING.GPL-3             GNU General Public License, version 3

--------------------------------------------------------------------------------
 What is distributed
--------------------------------------------------------------------------------
KVRouite is written with Qt for Python. The Windows build contains the Qt 6.11.2
runtime libraries (122 Qt6 modules in "_internal/PySide6"), the PySide6 bindings
and shiboken6. Among them is Qt WebEngine, which KVRouite uses to display the
map; it embeds a Chromium-derived engine with its own upstream licenses.

These are the prebuilt binaries published by the Qt Project on PyPI as the
PySide6 wheels. KVRouite does not compile, patch or otherwise modify them. They
are passed on exactly as pip installs them.
