Third-party code inside Qt WebEngine (Chromium)
===============================================

KVRouite displays its map in a Qt WebEngine view. Qt WebEngine embeds a
Chromium-derived browser engine; on Windows it is the file
_internal/PySide6/Qt6WebEngineCore.dll, by far the largest single file of this
distribution.

Chromium's own code is under the 3-clause BSD license. That text is in
"LICENSE.chromium" next to this file, reproduced unchanged, which is what the
BSD license asks of anyone passing the binaries on.

Chromium in turn contains code from the projects listed below, each under its
own license. The Qt Company publishes this list for the exact version shipped
here; it is reproduced unchanged.

  Qt version        6.11.2
  Chromium version  140.0.7339.225
                    (read out of Qt6WebEngineCore.dll of this build)
  Source            https://doc.qt.io/qt-6.11/qtwebengine-licensing.html
  Retrieved         2026-08-30

The Qt Company states that of all licenses occurring in the Chromium part, the
most restrictive is the GNU Lesser General Public License version 2.1, and that
the GPL-licensed parts listed below are only used to reach Linux system
resources - Qt WebEngine neither links to nor distributes GPL binary code.

The full text of every license below travels with the corresponding source of
Qt WebEngine, in "src/3rdparty/chromium" of the Qt WebEngine sources. Where to
obtain those sources is written in "CORRESPONDING-SOURCE.txt" next to this file.
