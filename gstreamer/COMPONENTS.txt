Note on FFmpeg
-----------------------------
KVRouite ships the FFmpeg 7.1 shared libraries (libavcodec, libavformat,
libavutil, libswresample, libswscale) inside gstreamer-plugins-libs. They are
used by the GStreamer gst-libav plugin. This is an LGPL build and is covered
by this file and by NOTICE.txt.

Nothing else of FFmpeg is distributed. The ffmpeg and ffprobe programs are
not part of this application: rendering runs through GES, and copy mode calls
whatever ffmpeg and ffprobe the user has installed. Without them copy mode
stays disabled.
